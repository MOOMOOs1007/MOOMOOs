환생 룰렛 사용설명서
====================

1. 프로그램 소개
----------------
SOOP 생방송 채팅을 30초 동안 수집한 뒤, 수집된 채팅 중 하나를 룰렛으로 뽑아 환생 조건을 완성하는 방송용 콘텐츠입니다.


2. Vercel 배포 방법
------------------
1) 환생룰렛-vercel 폴더의 파일을 GitHub 저장소에 올립니다.
2) Vercel에서 Add New Project를 선택합니다.
3) 해당 GitHub 저장소를 불러옵니다.
4) Framework Preset은 Other를 선택합니다.
5) Build Command와 Output Directory는 입력하지 않습니다.
6) Deploy를 눌러 배포합니다.

환경 변수나 SOOP 로그인 정보는 필요하지 않습니다.
공개 상태로 생방송 중인 방송만 연결할 수 있습니다.


3. 방송 연결 방법
----------------
1) SOOP 방송국 ID 또는 라이브 주소를 입력합니다.

입력 예시:
https://play.sooplive.com/아이디/방송번호

2) 방송 연결 버튼을 누릅니다.
3) 방송이 확인되면 연결된 스트리머의 닉네임과 '연결됨' 상태가 표시됩니다.

방송 연결 버튼은 방송 정보만 확인합니다.
이 버튼을 눌러도 채팅 수집은 시작되지 않습니다.


4. 채팅 수집 방법
----------------
1) 먼저 방송 연결을 완료합니다.
2) 수집할 환생 조건 카드를 선택합니다.
3) 필요하다면 채팅 시작 문자 조건을 선택합니다.
4) 채팅 수집 버튼을 누릅니다.
5) 30초 동안 방송 채팅이 수집됩니다.

수집 중에는 채팅 수집 버튼과 상태 영역에 남은 시간이 표시됩니다.
수집된 채팅은 오른쪽 '모인 채팅' 목록에 실시간으로 나타납니다.

같은 시청자가 여러 번 채팅해도 모든 채팅이 각각 별도의 후보로 저장됩니다.
예를 들어 한 시청자가 '한국'과 '미국'을 차례로 입력하면 두 채팅 모두 추첨 후보에 포함됩니다.
새로 채팅 수집을 시작하면 현재 선택된 항목의 기존 후보와 추첨 결과가 초기화됩니다.


5. 채팅 시작 문자 필터
----------------------
선택할 수 있는 문자는 다음과 같습니다.

!  @  #  ?

예를 들어 !를 선택하면 !로 시작하는 채팅만 수집합니다.

수집 예시:
!대한민국
!아이슬란드

문자 필터는 한 번에 하나만 선택할 수 있습니다.
다른 문자를 선택하면 이전 선택은 자동으로 해제됩니다.
선택된 문자를 다시 누르면 필터가 해제되고 전체 채팅을 수집합니다.
수집 중에는 필터를 변경할 수 없습니다.


6. 환생 조건 항목
----------------
기본 항목은 다음 순서로 구성되어 있습니다.

1) 나라
2) 성별
3) 외모/신체
4) 가정 환경
5) 재산
6) 재능
7) 성격
8) 직업
9) 결혼여부
10) 특별 이벤트
11) 말년


7. 항목 ON/OFF 설정
-------------------
'환생 조건 설정' 영역에서 각 항목의 스위치를 켜거나 끌 수 있습니다.

ON:
현재 환생에서 채팅 수집과 추첨에 사용합니다.

OFF:
카드는 흐릿하게 표시되며 '이번 환생에서 제외' 상태가 됩니다.
채팅 수집, 추첨, 다음 항목 이동, 진행률 계산에서 제외됩니다.

최소 한 개의 항목은 반드시 ON 상태로 유지됩니다.


8. 사용자 항목 추가
-------------------
1) 환생 조건 설정 아래의 '새 환생 조건 항목' 입력란에 이름을 적습니다.
2) 항목 추가 버튼을 누릅니다.
3) 추가된 항목도 기본 항목과 동일하게 ON/OFF 및 직접 답변 기능을 사용할 수 있습니다.

항목은 기본 항목을 포함해 최대 30개까지 사용할 수 있습니다.


9. 직접 답변 추가
----------------
각 항목 옆의 '직접 답변 1개' 입력란에 원하는 답변을 하나 적고 '답변 완료' 버튼을 누릅니다.

예시:
나라 - 대한민국
직업 - 아이돌
특별 이벤트 - 복권 1등

답변 완료를 누른 직접 답변은 해당 항목의 채팅 수집을 시작할 때 후보 목록에 자동으로 추가됩니다.
채팅 시작 문자 필터와 관계없이 항상 후보에 포함됩니다.
방송용 화면의 해당 항목 가장 오른쪽에는 '직접 답변 : 내용' 형식으로 표시됩니다.


10. 뽑기와 다시 뽑기
--------------------
뽑기:
수집된 후보 중 하나를 룰렛으로 선택하고 팝업 모달에서 결과를 보여 줍니다.

리롤:
팝업 모달 안에서 새로 채팅을 수집하지 않고 기존 후보 목록으로 다시 추첨합니다.

확정:
팝업 모달에 나온 결과를 해당 환생 조건의 최종 결과로 저장합니다.

수집된 후보가 없으면 뽑기 버튼을 사용할 수 없습니다.


11. 다음 항목
-------------
다음 항목 버튼을 누르면 아직 결과가 정해지지 않은 다음 ON 항목으로 이동합니다.
OFF 상태인 항목은 자동으로 건너뜁니다.


12. 전체 초기화
---------------
전체 초기화 버튼을 누르면 다음 내용이 초기화됩니다.

- 모든 환생 조건의 추첨 결과
- 모든 항목의 수집 채팅
- 현재 라운드 진행 상태

다음 내용은 유지됩니다.

- 방송 주소와 연결 정보
- 항목 ON/OFF 설정
- 사용자가 추가한 항목
- 항목별 직접 답변
- 채팅 시작 문자 필터


13. 방송용 화면
---------------
상단의 '방송용 화면' 버튼을 누르면 조작 버튼이 숨겨진 별도 화면이 열립니다.

OBS 브라우저 소스에는 Vercel 배포 주소 뒤에 다음 값을 붙인 주소를 입력합니다.

?overlay=1

예시:
https://내주소.vercel.app/?overlay=1

조작 화면과 방송용 화면은 같은 브라우저에서 열어야 실시간으로 동기화됩니다.
조작 화면에서 뽑기 또는 리롤을 누르면 방송용 화면에서도 같은 팝업 룰렛이 돌아가고 동일한 결과가 표시됩니다.
조작 화면에서 확정 버튼을 누르면 방송용 화면의 룰렛 팝업도 함께 닫힙니다.


14. 지원 범위 및 제한
--------------------
- 공개 상태로 생방송 중인 SOOP 방송만 지원합니다.
- 로그인, 성인 인증 또는 비밀번호가 필요한 방송은 지원하지 않습니다.
- SOOP 채팅 방식이 변경되면 프로그램 수정이 필요할 수 있습니다.
- Vercel 무료 플랜의 함수 실행 시간과 사용량 제한을 확인해 주세요.
- 배포 파일을 수정한 뒤에는 Vercel에 다시 배포해야 변경 사항이 적용됩니다.
- 변경 후 이전 화면이 보이면 브라우저에서 강력 새로고침을 해주세요.
