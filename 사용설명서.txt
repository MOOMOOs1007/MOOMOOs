환생 룰렛 사용설명서
====================

1. 프로그램 소개
----------------
SOOP 생방송 채팅을 30초 동안 수집한 뒤 자동으로 룰렛을 돌려 환생 조건을 완성하는 방송용 콘텐츠입니다.

2. Vercel 배포 방법
------------------
1) 환생룰렛-vercel 폴더의 파일을 GitHub 저장소에 올립니다.
2) Vercel에서 Add New Project를 선택하고 저장소를 불러옵니다.
3) Framework Preset은 Other를 선택합니다.
4) Build Command와 Output Directory는 입력하지 않고 Deploy합니다.

환경 변수나 SOOP 로그인 정보는 필요하지 않습니다. 공개 생방송만 연결할 수 있습니다.

3. 방송 연결
------------
1) SOOP 방송국 ID 또는 라이브 주소를 입력합니다.
   예: https://play.sooplive.com/아이디/방송번호
2) 방송 연결 버튼을 누릅니다.
3) 연결된 스트리머의 닉네임과 연결 상태를 확인합니다.

방송 연결 버튼은 방송 정보만 확인하며 채팅 수집을 시작하지 않습니다.

4. 항목 등록과 자동 추첨
-----------------------
1) 추첨할 항목 오른쪽의 '후보 하나 입력' 칸에 기본 후보를 적습니다.
2) 내용이 입력되어야 등록 버튼이 활성화됩니다.
3) 등록을 누르면 입력한 후보가 후보 목록에 포함되고 채팅 수집 모달이 열립니다.
4) 연결된 방송의 채팅을 30초간 수집합니다.
5) 수집되는 채팅은 모달과 오른쪽 '모인 채팅' 목록에 실시간으로 표시됩니다.
6) 수집이 끝나면 별도의 뽑기 버튼 없이 룰렛이 자동으로 시작됩니다.
7) 룰렛이 멈추면 리롤과 확정 버튼이 활성화됩니다.

리롤은 새로 수집하지 않고 같은 후보 목록에서 다시 뽑습니다.
확정은 현재 결과를 해당 환생 조건의 최종 결과로 저장합니다.
같은 시청자가 여러 번 채팅해도 모든 채팅을 각각 별도 후보로 저장합니다.

채팅이 없을 때는 화면 아래의 '테스트 후보 채우기'를 누릅니다.
현재 항목에 정상적인 답변과 재미있는 엉뚱한 답변이 섞인 후보 12개가 추가되고 룰렛이 바로 시작됩니다.

5. 환생 조건 항목
----------------
기본 항목은 나라, 성별, 외모/신체, 가정 환경, 재산, 재능, 성격, 직업, 결혼여부, 특별 이벤트 순서입니다.

각 카드 왼쪽의 스위치로 ON/OFF를 설정합니다.
ON 항목은 수집, 추첨, 진행률에 사용합니다.
OFF 항목은 사라지지 않고 흐릿하게 표시되며 이번 환생에서 제외됩니다.
최소 한 항목은 ON 상태로 유지됩니다.

6. 사용자 항목 추가
-------------------
목록 위의 '새 환생 조건 항목' 칸에 이름을 적고 항목 추가를 누릅니다.
추가 항목도 기본 항목과 같은 ON/OFF, 후보 등록, 수집, 추첨 기능을 사용합니다.
항목은 최대 30개까지 만들 수 있습니다.

7. 직접 등록 후보
-----------------
각 항목의 오른쪽 입력란에 입력한 후보는 등록과 동시에 해당 항목의 첫 후보가 됩니다.
다시 등록하면 해당 항목의 이전 후보와 결과를 비우고 새로운 30초 수집을 시작합니다.

8. 전체 초기화
-------------
전체 초기화는 모든 결과, 수집 채팅, 현재 진행 상태를 초기화합니다.
방송 주소와 연결 정보, ON/OFF 설정, 추가 항목과 입력한 후보는 유지됩니다.

9. 지원 범위 및 제한
--------------------
- 공개 상태로 생방송 중인 SOOP 방송만 지원합니다.
- 로그인, 성인 인증 또는 비밀번호가 필요한 방송은 지원하지 않습니다.
- SOOP 채팅 방식이 변경되면 프로그램 수정이 필요할 수 있습니다.
- 배포 파일을 수정한 뒤에는 Vercel에 다시 배포해야 합니다.
- 이전 화면이 보이면 브라우저에서 강력 새로고침을 해주세요.
