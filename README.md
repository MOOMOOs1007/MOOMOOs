# 환생 룰렛 — Vercel 자동 수집 버전

정적 HTML/CSS/JS 화면과 Vercel Function을 함께 배포합니다. **방송 연결**은 현재 생방송과 스트리머를 확인하고, 별도의 **채팅 수집** 버튼이 연결된 방송의 채팅을 30초 동안 전달합니다.

## 배포

1. 이 폴더 전체를 GitHub 저장소 루트에 올립니다.
2. Vercel에서 **Add New Project → Import Git Repository**로 저장소를 선택합니다.
3. Framework Preset은 **Other**, Root Directory는 이 파일이 있는 폴더로 지정합니다.
4. Build Command와 Output Directory는 비워 둔 채 Deploy합니다.
5. 프로젝트 Settings → Functions에서 Fluid Compute가 활성화되어 있는지 확인합니다.

환경 변수나 SOOP 로그인 정보는 필요하지 않습니다. 공개 방송만 지원합니다.

## 동작 흐름

1. 항목을 선택합니다.
2. SOOP 방송 ID 또는 `https://play.sooplive.com/아이디/방송번호`를 입력합니다.
3. **방송 연결**을 눌러 현재 생방송과 스트리머 닉네임을 확인합니다.
4. 연결이 완료되면 **채팅 수집**을 누릅니다. 버튼과 상태 표시에 30초부터 남은 시간이 나타납니다.
5. 30초 동안 들어오는 채팅은 오른쪽 **모인 채팅** 목록에 실시간으로 표시됩니다. 같은 시청자가 여러 번 채팅해도 모든 채팅이 각각 별도의 후보로 저장됩니다.
6. 수집이 끝나면 **뽑기**를 눌러 모인 채팅 중 하나를 룰렛으로 선택합니다. 이후 **다시 뽑기**를 누르면 같은 후보 안에서 즉시 재추첨합니다.

채팅 시작 문자에서 `!`, `@`, `#`, `?` 중 하나를 선택하면 해당 문자로 시작하는 채팅만 수집합니다. 중복 선택은 지원하지 않으며, 선택한 문자를 다시 누르면 조건이 해제되어 전체 채팅을 수집합니다.

## 환생 조건 설정

기본 항목은 나라, 성별, 외모/신체, 가정 환경, 재산, 재능, 성격, 직업, 결혼여부, 특별 이벤트, 말년 순서입니다. 각 항목의 스위치를 끄면 카드는 흐릿한 OFF 상태로 남고 현재 환생 라운드의 채팅 수집, 추첨, 진행률에서는 제외됩니다.

설정 영역에서 새 항목을 직접 추가할 수 있습니다. 각 항목의 **직접 답변 1개** 입력란에 내용을 적고 **답변 완료**를 누르면 해당 항목의 채팅 수집 후보에 자동으로 포함됩니다. 완료된 답변은 방송용 화면 카드의 오른쪽에 `직접 답변 : 내용` 형식으로 표시됩니다. 전체 초기화를 해도 항목 설정과 직접 답변은 유지됩니다.

뽑기를 누르면 룰렛 모달에서 결과를 먼저 보여 줍니다. 모달 안의 **리롤**로 같은 후보에서 다시 뽑거나 **확정**으로 최종 결과를 저장할 수 있습니다.

상단의 **방송용 화면 ↗**을 누르면 조작부를 숨긴 별도 화면이 열립니다. 같은 브라우저에서 연 두 화면은 실시간으로 동기화되며, 수집되는 채팅 후보와 스트리머 닉네임이 방송용 화면에 즉시 표시됩니다. OBS에는 방송용 화면의 URL(`?overlay=1`)을 브라우저 소스로 추가하면 됩니다.

컨트롤 화면에서 뽑기 또는 리롤을 실행하면 방송용 화면에도 같은 룰렛 팝업이 열리고 동일한 후보 순서와 결과가 표시됩니다. 컨트롤 화면에서 결과를 확정하면 두 화면의 팝업이 함께 닫힙니다.

## 제한

- SOOP 비공식 프로토콜을 사용하므로 플랫폼 변경 시 수정이 필요할 수 있습니다.
- 로그인, 성인 인증, 비밀번호가 필요한 방송은 지원하지 않습니다.
- Vercel Function은 한 번의 수집 요청에서만 상태를 유지합니다. 새로고침하면 수집 결과가 사라집니다.
- 무료 플랜의 사용량과 동시 실행 제한을 확인하세요. 방송 시청자가 이 페이지를 각자 열어 수집하면 사용자마다 별도의 Function이 실행됩니다.
- `api/chat.js`는 서버에서 당첨자를 정하지 않습니다. 수집된 후보는 해당 브라우저 메모리에만 남고, 룰렛 추첨은 Web Crypto 난수를 사용합니다.

## 로컬 실행

Node.js 24 이상에서:

```bash
npm install
npx vercel dev
```

프로토콜 테스트:

```bash
npm test
```

## 파일

- `index.html`, `style.css`, `vercel.css`, `app.js`: 방송 화면 및 룰렛
- `api/chat.js`: SOOP 채팅 30초 스트리밍 함수
- `api/protocol.js`: SOOP 채팅 패킷 생성·해석
- `test/protocol.test.js`: UTF-8 패킷, 입장 패킷, URL 입력 테스트
