# 환생 룰렛 — Vercel 자동 수집 버전

정적 HTML/CSS/JS 화면과 Vercel Function을 함께 배포합니다. **방송 연결**은 현재 생방송과 스트리머를 확인하며, 각 항목의 후보를 입력하고 **등록**하면 연결된 방송의 채팅을 30초 동안 수집합니다.

## 배포

1. 이 폴더 전체를 GitHub 저장소 루트에 올립니다.
2. Vercel에서 **Add New Project → Import Git Repository**로 저장소를 선택합니다.
3. Framework Preset은 **Other**, Root Directory는 이 파일이 있는 폴더로 지정합니다.
4. Build Command와 Output Directory는 비워 둔 채 Deploy합니다.
5. 프로젝트 Settings → Functions에서 Fluid Compute가 활성화되어 있는지 확인합니다.

환경 변수나 SOOP 로그인 정보는 필요하지 않습니다. 공개 방송만 지원합니다.

## 동작 흐름

1. SOOP 방송 ID 또는 `https://play.sooplive.com/아이디/방송번호`를 입력합니다.
2. **방송 연결**을 눌러 현재 생방송과 스트리머 닉네임을 확인합니다.
3. 추첨할 항목 오른쪽 입력란에 기본 후보 하나를 입력합니다. 내용이 있을 때만 **등록** 버튼이 활성화됩니다.
4. **등록**을 누르면 입력한 후보가 목록에 포함되고 30초 수집 모달이 열립니다.
5. 방송 채팅은 모달의 맨 위에 최신순으로 실시간 표시됩니다. 같은 시청자의 여러 채팅도 각각 별도 후보로 저장됩니다.
6. 수집이 끝나면 모달의 **룰렛 돌리기**를 누릅니다. 결과가 나온 뒤 **리롤** 또는 **확정**을 선택합니다.

방송 채팅 없이 진행해야 할 때는 **테스트 후보 채우기**를 누릅니다. 현재 항목에 정상적인 답변과 엉뚱한 답변이 섞인 테스트 후보 12개가 들어가며, 모달에서 **룰렛 돌리기**를 눌러 시작합니다.

## 환생 조건 설정

기본 항목은 나라, 성별, 외모/신체, 가정 환경, 재산, 재능, 성격, 직업, 결혼여부, 특별 이벤트 순서입니다. 각 항목의 스위치를 끄면 카드는 흐릿한 OFF 상태로 남고 현재 환생 라운드의 채팅 수집, 추첨, 진행률에서는 제외됩니다.

목록 위의 입력란에서 새 항목을 직접 추가할 수 있습니다. 각 카드의 왼쪽 스위치로 항목을 켜거나 끄며, 오른쪽 입력란과 **등록** 버튼으로 해당 항목의 수집과 추첨을 시작합니다.

수집이 끝나면 모달의 **룰렛 돌리기**가 활성화됩니다. 결과가 나온 뒤 **리롤**로 같은 후보에서 다시 뽑거나 **확정**으로 최종 결과를 저장할 수 있습니다.

## 제한

- SOOP 비공식 프로토콜을 사용하므로 플랫폼 변경 시 수정이 필요할 수 있습니다.
- 로그인, 성인 인증, 비밀번호가 필요한 방송은 지원하지 않습니다.
- Vercel Function은 한 번의 수집 요청에서만 상태를 유지합니다. 새로고침하면 수집 결과가 사라집니다.
- 무료 플랜의 사용량과 동시 실행 제한을 확인하세요. 방송 시청자가 이 페이지를 각자 열어 수집하면 사용자마다 별도의 Function이 실행됩니다.
- `api/chat.js`는 서버에서 당첨자를 정하지 않습니다. 수집된 후보는 해당 브라우저 메모리에만 남고, 룰렛 추첨은 Web Crypto 난수를 사용합니다.

## 로컬 실행

Node.js 24 이상에서:

```bash
npm install
npx vercel dev
```

프로토콜 테스트:

```bash
npm test
```

## 파일

- `index.html`, `style.css`, `vercel.css`, `app.js`: 방송 화면 및 룰렛
- `api/chat.js`: SOOP 채팅 30초 스트리밍 함수
- `api/protocol.js`: SOOP 채팅 패킷 생성·해석
- `test/protocol.test.js`: UTF-8 패킷, 입장 패킷, URL 입력 테스트
